Step 2: Create a new bookmark:

  • Chrome/Edge: Press Ctrl+Shift+B (Windows) or Cmd+Shift+B (Mac) to open Bookmark Manager
  • Click the three dots menu → Add new bookmark
  • Name: Case Title Updater
  • URL: Paste the code you copied above
  • Click Save

Step 3: Use the bookmark

  • Go to your Dynamics 365 case page
  • Click the Case Title Updater bookmark
  • A popup will appear - select code and date
  • Click Preview or Apply
